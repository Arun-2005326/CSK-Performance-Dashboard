# CSK-Performance-Dashboard

## Project Overview

This project is an interactive Power BI dashboard that analyzes the performance of Chennai Super Kings (CSK) in the Indian Premier League (IPL).

The dashboard provides visual insights into team performance, match results, player statistics, and season-wise trends.

## Objectives

* Analyze CSK's IPL performance
* Visualize key performance indicators (KPIs)
* Identify top-performing players
* Track win/loss trends across seasons
* Present insights through interactive Power BI visualizations

## Tools Used

* Power BI
* Microsoft Excel / CSV Dataset

## Dashboard Features

* Total Matches Played
* Total Wins and Losses
* Win Percentage
* Season-wise Performance
* Top Run Scorers
* Top Wicket Takers
* Match Result Analysis
* Interactive Filters and Slicers

## Key Insights

* CSK has maintained one of the highest win percentages in IPL history.
* Certain players consistently contributed to team success.
* Home-ground matches showed stronger performance trends.
